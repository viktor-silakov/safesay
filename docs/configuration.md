# Настройка safesay

## Файл настроек

Настройки хранятся в `~/.config/safesay/config.json`. Поле `mode` задаёт режим `foreground` или `background`. В `allowedApps` перечислены идентификаторы приложений, которым разрешено использовать микрофон одновременно с озвучкой.

```json
{
  "mode": "foreground",
  "allowedApps": ["com.example.Dictation"]
}
```

`safesay --mic-status` показывает активные приложения, их идентификаторы и пометки `allowed` или `blocked`. Для процесса без идентификатора приложения команда может показать путь к бинарнику. Этот путь тоже подходит для `--allow-app`. Чтобы убрать исключение, удалите его из `allowedApps`.

## Если фраза ждёт

Выполните `safesay --mic-status`. Любая строка с `blocked` означает, что один из процессов держит аудиовход. Освободите микрофон в этом приложении или добавьте его в исключения. У браузеров исключение действует на все вкладки.

В фоновом режиме код выхода `0` означает, что команда приняла фразу в очередь. Ошибки самого `say`, например неверное имя голоса, появляются в `~/Library/Application Support/safesay/worker.log`. Для запуска фонового режима нужна открытая пользовательская сессия macOS.

При ожидании фоновые фразы сохраняются локально в `~/Library/Application Support/safesay/queue`. Утилита удаляет задание после завершения `say`. Если фоновый процесс остановился посреди фразы, задание остаётся на диске и может повториться при следующем запуске агента.

## Как удалить команду

Выполните `safesay --mode foreground`. Если в очереди есть фразы, дождитесь, пока LaunchAgent озвучит их и завершится. Затем удалите бинарник `~/.local/bin/safesay`. Настройки и журнал можно удалить отдельно, если они больше не нужны.
