# Repository language

Use English for all repository content, including documentation, source code comments, command-line messages, examples, tests, and configuration descriptions.

Write commit messages and pull request titles and descriptions in English.

## Commits and pushes

For significant changes, run the relevant checks, commit all changes made for the task, and push the working branch to `origin` before reporting completion. This applies to features, bug fixes, and substantial changes to installation, documentation, or project rules.
